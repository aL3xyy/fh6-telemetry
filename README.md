# FH6 Telemetry

A telemetry application for Forza Horizon 6, written in Go.

## Overview

FH6 Telemetry is a project focused on extracting and displaying real-time vehicle data from Forza Horizon 6. The goal is to provide a lightweight telemetry solution that makes in-game vehicle data accessible for monitoring, analysis, and potential integration with external tools.

Built with Go, the project aims to keep the telemetry pipeline efficient and straightforward while providing a foundation for future extensions.

The current implementation runs in the terminal, with the telemetry interface designed and ready for integration. Development is focused on establishing communication with the game, parsing incoming telemetry data, and connecting the data stream to the existing display.

## Current Progress

* Terminal-based telemetry interface
* Telemetry display design completed
* Data integration and packet parsing pending
* Standalone Windows executable planned

## Roadmap
